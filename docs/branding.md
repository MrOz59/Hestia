# Product names and compatibility

Use **Hestia** in desktop UI text, stream titles, CLI help, SDL application names, and package descriptions. The Qt display name is Hestia; translated sources and translations use the same product name.

The following identifiers are intentionally retained:

- Qt organization/application settings identity, so existing paired hosts, preferences, caches, and portable installations remain readable.
- The `moonlight` executable, desktop-file ID, icon resource names, and legacy URI scheme, which existing packages and launchers use.
- Protocol checks for `base: Apollo`, upstream library names, upstream service/tool names, and license credits.

Changing storage or installation identifiers requires an explicit migration. Hermes, Apollo, Sunshine, and GeForce Experience remain supported host names.
